# Interview Copilot

## Назначение
Личное приложение для macOS (строка меню + плавающая панель), которое слушает собеседника
в Google Meet / Zoom / Telegram, локально расшифровывает речь (украинский, русский, английский),
находит вопрос в заранее подготовленной базе ответов владельца и показывает ответ.
Если вопроса нет в базе, по выбранному режиму генерирует подсказку через Gemini
с переходом на DeepSeek или Claude. Пользователь один — владелец; распространение не планируется.

Статус: **проект создаётся**. Код ещё не написан; требования и план — в `docs/changes/COPILOT-01/`.

## Требования к среде
- Mac на Apple Silicon, macOS 15+ (проверено на M1 8 ГБ, macOS 15.7.2).
- Swift 6 (Command Line Tools). Xcode — только если без него не работают тесты (решение в plan.md, P-00).
- Свободно ≥ 3 ГБ на модели распознавания и эмбеддингов.
- Ключ Gemini API (бесплатный тариф). DeepSeek и Anthropic — по желанию.

## Быстрый запуск
> Команды ниже — **новые**, появятся на шагах plan.md (P-01, P-04). До этого они не работают.

- Сборка: `swift build`
- Тесты: `swift test`
- Сборка `.app`: `scripts/build-app.sh`
- Скачивание моделей: `scripts/fetch-models.sh`
- Запуск: `open dist/InterviewCopilot.app`

## Проверка
- Юнит-тесты: `swift test`
- Evals (поиск по базе, конец вопроса): `scripts/run-evals.sh` — см. `evals/README.md`
- Поиск секретов и личных данных в репозитории: `scripts/secret-scan.sh`

## Структура
- `Sources/` — код приложения (появится в P-01)
- `Tests/` — тесты
- `scripts/` — сборка, модели, evals, проверки
- `profile.example/` — пример профиля (резюме, вакансия, истории, база вопросов)
- `evals/` — наборы данных и пороги для недетерминированных частей
- `docs/design/` — визуальные референсы (сгенерированные изображения меню)
- `docs/decisions/` — архитектурные решения (ADR)
- `docs/changes/COPILOT-01/` — intent, spec, plan, handoff, промпт исполнителя

## Ограничения и безопасность
- API-ключи — только в Связке ключей macOS. Не в коде, не в логах, не в чате, не в Git.
- Личный профиль и история сессий — в `~/Library/Application Support/InterviewCopilot/`, в Git не попадают.
- Аудио на диск не записывается; сохраняется только текст сессий (срок хранения настраивается).
- Репозиторий приватный: `itmax04/interview-copilot`.
