# Живой сценарий тестового созвона (H-4)

Для AC-01…AC-03, AC-05, AC-09, AC-10. Данные синтетические: вопросы к вымышленному кандидату из `profile.example/`.
Метрики считает `scripts/metrics.py` по логам приложения (там только числа, без текста реплик).

## Подготовка (≈ 3 мин)
1. На Mac: Google Chrome → meet.google.com → «Новая встреча» → «Начать встречу сейчас». Скопировать ссылку.
2. На телефоне: открыть ссылку (приложение Meet или браузер), войти во встречу. **На Mac выключить свой микрофон в Meet**,
   чтобы телефон не слышал эхо, и надеть наушники, если есть (без них тоже можно).
3. В меню попугая: «Listening — Chrome» (или Auto), точка зелёная; режим «Bank + hint»; язык «Auto (UK/RU/EN)».
4. Исполнитель запускает в Терминале замер памяти `scripts/footprint-monitor.sh 10` (AC-05).

## Проверки по ходу (AC-09)
- После вопроса 3: щёлкнуть в окно Chrome (фокус на Chrome) и нажать **⌃⌥H** дважды — панель скрывается и появляется,
  фокус остаётся в Chrome (курсор в адресной строке не пропадает).
- После вопроса 9: не дожидаясь ответа, нажать **⌃⌥↩** — ответ сразу по последней реплике.
- После вопроса 14: открыть в Chrome любую страницу с текстом задачи и нажать **⌃⌥S** — решение в панели.
- Во время вопроса 12 начать говорить самому в микрофон Mac — автоответ не должен перебить (S-07); затем ⌃⌥↩.
