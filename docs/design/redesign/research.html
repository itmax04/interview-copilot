2. Floating panel — the main screen during a call

Structure

A vertical dark HUD panel 380×420: header (parrot, status capsule, model, latency) → "INTERVIEWER" with the last three lines → answer card (source, Markdown, Copy, ↑ Claude) → footer with hotkey hints.

What works

The answer is readable: a bold first line, short bullets, a large font; gray filtered lines are clickable.
It does not take focus from the call (non-activating panel), shows on all desktops, size and position are remembered.

Problems

No action bar: Answer, Screenshot, Chat are available only via hotkeys; the hotkey hints in the footer are small and far from the content.
No "Question: …" header above the answer — it is unclear what exactly is being answered (especially after the question changes).
No answer history: a new answer erases the previous one; you cannot go back to an answer from 2 minutes ago.
Question-detection states are invisible: "checking / question detected / not a question" happen silently.
While an answer is being prepared the previous one disappears entirely — an empty space instead of a dimmed "previous".
Lots of empty space: with 3 transcript lines and a short answer half of the panel is empty; the height does not adapt.
The self-check footer wraps words mid-word — 4 hints do not fit into 380 pt.
Mixed languages: "Listening", "Thinking…", "Copy", "INTERVIEWER" next to Russian text.
A screenshot answer shows "Waiting for the other person to speak…" — the transcript state is unrelated to the task.
No session timer, no End button, no microphone and call-audio indicators — it is unclear whether the app hears the call.

3. "Profile" window

Structure

Header (profile picker, New / Rename / Delete / Folder) → six tabs → each with an explanation, an upload button, a text editor or a list with details.

Problems

The résumé is shown as raw Markdown in a monospaced editor ("## Опыт", "- …"); no document preview.
Long gray explanations above every tab take the first screen and repeat each other.
Questions: the right side is empty on open ("Select a question"); statuses are colored capsules without a legend; "+5" is unclear without a tooltip.
Materials: no per-file state (read / indexing / ready / error) — only one status line on the right.
Profile, questions, materials, history and settings are five separate windows; there is no single "main window".
It is not visible what from the profile actually goes into a request (characters only in the footer) or how the profile relates to a session.

4. Settings

Eight tabs with English names; Audio is about 2 screens of technical toggles (Whisper turbo, Silero, LocalVQE, thresholds in ms).
No "basic / advanced" split: pause thresholds, the bank threshold and model IDs sit next to the main choices.
Keys: a long list of identical provider cards; it is unclear which key is the minimum (now — Groq).
Bank and Panel hold one or two settings per tab; "Bank" is an outdated name (now profile questions).
Strengths: everything is configurable without files; key checks, hotkey remapping and a budget exist.

5. History, first launch, browser pages

History: answers are shown as raw Markdown ("**…**", "- …"); the date is in English ("Oct 19, 2026"); no review, comments, search or "interviewer / you" split.
First launch is outdated: a "Gemini key" step although free Groq is first in the chain; the microphone permission text "your voice is not transcribed" is wrong since COPILOT-05.
Three visual languages: a dark HUD (panel), light system windows, dark web pages with their own style (AI interview, test call).
No main window or "home" screen: the user starts from the menu bar and cannot see whether everything is ready for a call.

6. Summary analysis and requirements for the new design

Structure

  • The app is a set of scattered windows around the menu bar. A hierarchy is needed: a main window (preparation, history, profiles, settings) + a live overlay (the call only) + the menu bar (quick access).
  • There is no "session" object: preparation, the call and the review are not connected. COPILOT-09 introduces a wizard, Start/End and a review — the design is built around the lifecycle Preparation → Check → Call → Review.

Visual design

  • One language: dark "glass" for the overlay, native macOS windows with the same accent palette and typography for the main window; browser pages in the same palette.
  • One accent (indigo/blue), semantic state colors (green — listening, amber — checking/draft, red — error/End), SF Pro, a 4/8 pt grid, corner radii 10–16 pt.
  • The whole interface in Russian; only model names and keys in English.

Usability

  • Main actions as visible buttons with hotkey hints (as in ParakeetAI), not only as hotkeys.
  • Explicit, separate states: audio source, recognition, question, generation, error.
  • Reading while speaking: a question header, a large first answer line, ←/→ history, no scroll jumps.
  • Settings: basic separate from advanced; the minimum to start (one free key) is obvious.

7. How to use the prompts in ChatGPT

  1. First P00 — the style guide. Save the result: it is the reference image.
  2. For every following prompt attach the P00 image and write before the prompt: "Use the attached style guide exactly (colors, typography, radii, glass material)". That keeps all screens in one style.
  3. The size is given in each prompt (usually 1536×1024; overlay — 1024×1536). If the Cyrillic text is garbled, ask to "re-render with crisp, correctly spelled Russian UI text" or generate an English version.
  4. Make 2–3 variants per screen and pick the best. File names: P07-overlay-answer.png etc.
  5. Send the images here — the final redesign after COPILOT-09 is based on them.
Common style block (already embedded in every prompt below): macOS 15 Sequoia native app, Apple Human Interface Guidelines, SF Pro typography, 8-pt grid, corner radius 12–16 px, subtle 1-px hairlines, accent color indigo #4C6EF5, semantic colors: green #2FB344 (listening), amber #F59F00 (checking / draft), red #E03131 (error / end), neutral graphite. Live overlay: dark translucent glass (#16181D at 82% with background blur), white text. Main windows: light, clean, generous whitespace, sidebar navigation. UI language Russian. High-fidelity product mockup, pixel-perfect, no device frame, no watermark, no lorem ipsum, realistic content about an iOS developer interview.
