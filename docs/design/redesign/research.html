1. Как проводилось исследование

Каждое окно отрисовано самим приложением в служебном режиме --ui-snapshots: настоящие SwiftUI-представления, синтетический профиль из profile.example/, материалы из evals/materials/, вымышленная сессия. Звук, микрофон и запросы к моделям не включались; данные — во временной папке, удалённой после съёмки.

2. Плавающая панель — главный экран во время звонка

Структура

Вертикальная тёмная HUD-панель 380×420: шапка (попугай, статус-капсула, модель, задержка) → «INTERVIEWER» с тремя последними репликами → карточка ответа (источник, Markdown, Copy, ↑ Claude) → подвал с подсказками клавиш.

Что хорошо

Ответ читается: жирная первая строка, короткие пункты, крупный шрифт; серые отфильтрованные реплики кликабельны.
Не забирает фокус у звонка (nonactivating panel), на всех рабочих столах, размер и позиция запоминаются.

Проблемы

Нет панели действий: Answer, Screenshot, Chat доступны только клавишами; подсказки клавиш в подвале — мелкие и далеко от контента.
Нет заголовка «Вопрос: …» над ответом — неясно, на что именно ответ (особенно после смены вопроса).
Нет истории ответов: новый ответ стирает прошлый; нельзя вернуться к ответу 2 минуты назад.
Состояния распознавания вопроса не видны: «проверяю / вопрос найден / не вопрос» происходят молча.
Во время подготовки ответа прошлый ответ исчезает целиком — пустое место вместо приглушённого «предыдущего».
Много пустого места: при 3 строках расшифровки и коротком ответе половина панели пуста; высота не подстраивается.
Подвал в самопроверке переносит слова («скриншо-т», «конец / ответа») — 4 подсказки не помещаются в 380 pt.
Смесь языков: «Listening», «Thinking…», «Copy», «INTERVIEWER» рядом с русским текстом.
Ответ по скриншоту показывает «Жду, когда собеседник заговорит…» — состояние расшифровки не связано с задачей.
Нет таймера сессии, кнопки End, индикаторов микрофона и звука звонка — неясно, слышит ли приложение звонок.

3. Окно «Профиль»

Структура

Шапка (выбор профиля, Новый / Переименовать / Удалить / Папка) → шесть вкладок → в каждой: пояснение, кнопка загрузки, редактор текста или список с деталями.

Проблемы

Резюме показывается как сырой Markdown в моноширинном редакторе — «## Опыт», «- …»; нет предпросмотра документа.
Длинные пояснения серым над каждой вкладкой занимают первый экран; повторяются по смыслу.
Вопросы: при открытии правая часть пуста («Выберите вопрос»); статусы цветными капсулами без легенды; «+5» непонятно без подсказки.
Материалы: нет состояния каждого файла (прочитан / индексируется / готов / ошибка) — только одна строка статуса справа.
Профиль, вопросы, материалы, история и настройки — пять отдельных окон; нет единого «главного окна».
Не видно, что из профиля реально уходит в запрос (символы — только в подвале), и как профиль связан с сессией.

4. Настройки

Восемь вкладок с английскими названиями; Audio — около 2 экранов технических переключателей (Whisper turbo, Silero, LocalVQE, пороги в мс).
Нет разделения «обычное / продвинутое»: пороги паузы, порог базы, ID моделей стоят рядом с основными выборами.
Ключи: длинный список провайдеров одинаковыми карточками; непонятно, какой ключ нужен минимально (сейчас — Groq).
Bank и Panel — по одной-две настройки на целую вкладку; «Bank» — устаревшее имя (теперь вопросы профиля).
Сильные стороны: всё настраивается без файлов, есть проверка ключей, переназначение клавиш, бюджет.

5. История, первый запуск, браузерные страницы

История: ответы показаны сырым Markdown («**…**», «- …»); дата по-английски («Oct 19, 2026»); нет разбора, комментариев, поиска, разделения «интервьюер / вы».
Первый запуск устарел: шаг «Ключ Gemini», хотя первым в цепочке стоит бесплатный Groq; текст разрешения микрофона «голос не расшифровывается» — неверно с COPILOT-05.
Три визуальных языка: тёмный HUD (панель), светлые системные окна, тёмные веб-страницы со своим стилем (ИИ-собеседование, тестовый звонок).
Нет главного окна и «домашнего» экрана: пользователь начинает со строки меню и не видит, готово ли всё к звонку.

6. Сводный анализ и требования к новому дизайну

Структура

  • Приложение — набор разрозненных окон вокруг строки меню. Нужна иерархия: Главное окно (подготовка, история, профили, настройки) + Живой оверлей (только звонок) + строка меню (быстрый доступ).
  • Нет объекта «сессия»: подготовка, звонок и разбор не связаны. COPILOT-09 вводит мастер, Start/End, разбор — дизайн строится вокруг жизненного цикла Подготовка → Проверка → Звонок → Разбор.

Оформление

  • Единый язык: тёмное «стекло» для оверлея, нативные macOS-окна с той же акцентной палитрой и типографикой для главного окна; браузерные страницы — в той же палитре.
  • Один акцент (индиго/синий), семантические цвета состояний (зелёный — слушаю, янтарный — проверяю/черновик, красный — ошибка/End), шрифт SF Pro, сетка 4/8 pt, скругления 10–16 pt.
  • Весь интерфейс по-русски; английские только названия моделей и клавиши.

Удобство

  • Главные действия — видимыми кнопками с подсказками клавиш (как в ParakeetAI), не только клавишами.
  • Состояния — явные и раздельные: источник звука, распознавание, вопрос, генерация, ошибка.
  • Чтение во время речи: заголовок вопроса, первая строка ответа крупно, история ←/→, без прыжков прокрутки.
  • Настройки: базовое отдельно от продвинутого; минимум для старта (один бесплатный ключ) — очевиден.

7. Как пользоваться промптами в ChatGPT

  1. Сначала P00 — стиль-гайд. Сохраните результат: это опорное изображение.
  2. Для каждого следующего промпта прикладывайте картинку P00 и пишите перед промптом: «Use the attached style guide exactly (colors, typography, radii, glass material)». Так все экраны будут в одном стиле.
  3. Размер — указан в каждом промпте (обычно 1536×1024; оверлей — 1024×1536). Если текст на кириллице искажён — попросите «re-render with crisp, correctly spelled Russian UI text» или сгенерируйте английскую версию.
  4. Делайте 2–3 варианта на экран и выбирайте лучший. Имена файлов: P07-overlay-answer.png и т. д.
  5. Пришлите картинки сюда — по ним будет финальный редизайн после завершения COPILOT-09.
Общий блок стиля (он уже встроен в каждый промпт ниже): macOS 15 Sequoia native app, Apple Human Interface Guidelines, SF Pro typography, 8-pt grid, corner radius 12–16 px, subtle 1-px hairlines, accent color indigo #4C6EF5, semantic colors: green #2FB344 (listening), amber #F59F00 (checking / draft), red #E03131 (error / end), neutral graphite. Live overlay: dark translucent glass (#16181D at 82% with background blur), white text. Main windows: light, clean, generous whitespace, sidebar navigation. UI language Russian. High-fidelity product mockup, pixel-perfect, no device frame, no watermark, no lorem ipsum, realistic content about an iOS developer interview.
