# COPILOT-10: Spec

ID: COPILOT-10-spec · Статус: **accepted** · Версия: 1 · Дата: 2026-10-25
Связи: [intent.md](intent.md), [plan.md](plan.md)

## Требования
| ID | Требование |
|---|---|
| R-01 | `AppSettings.theme` (`system` / `light` / `dark`) и `interfaceLanguage` (`system` / `ru` / `en`); старые настройки читаются со значениями по умолчанию (`system`). Язык системы: ru/uk/be → русский, иначе английский |
| R-02 | Цвета окон — динамические токены `IC` (светлый и темный вариант); жестко заданных белых фонов и hex-цветов в окнах нет. Тема применяется `NSApp.appearance` сразу; оверлей закреплен темным (`.darkAqua`) |
| R-03 | «Настройки → Основное» (первая вкладка): тема и язык; те же переключатели — внизу онбординга |
| R-04 | Ключ строки — русский текст из кода; английский — `Resources/en.lproj/Localizable.strings`. Литералы SwiftUI — по `\.locale`, строки из переменных — перегрузками `Text(String)` и др., строки в коде — `L(…)` / `L10n.t/f` |
| R-05 | Смена языка — сразу: корень каждого окна перерисовывается (`localizedRoot`), заголовки окон переводятся заново, меню в строке состояния собирается заново при открытии |
| R-06 | Меню в строке состояния, ошибки, статусы, проверка перед стартом, даты и числительные — на языке интерфейса |
| R-07 | Разбор после звонка и «Спросить ИИ» — на языке интерфейса (заглушки «[цифра]» → «[number]»); подсказки на звонке не меняются |
| R-08 | Страницы ИИ-собеседования и тестового звонка — на языке интерфейса (словарь `en.json` рядом со страницей) |
| R-09 | `scripts/check-localization.sh` — у каждой строки интерфейса есть перевод и форматы совпадают; входит в полную проверку |

## Критерии приемки
| ID | Критерий | Как проверить |
|---|---|---|
| AC-01 | Тема меняется сразу во всех окнах; оверлей темный в любой теме | снимки `dark-*`, живая проверка H-1 |
| AC-02 | Язык меняется сразу, без перезапуска; вкладка настроек не сбрасывается | живая проверка H-1 |
| AC-03 | В английском интерфейсе нет русских строк интерфейса (кроме названий языков и пользовательских данных) | `scripts/check-localization.sh`, снимки `en-*`, тест страниц |
| AC-04 | Русский интерфейс не изменился (кроме исправленных английских пунктов меню) | `swift test`, снимки |
| AC-05 | Разбор и «Спросить ИИ» — на языке интерфейса | тест `reviewForTheOwnerIsWrittenInTheInterfaceLanguage` |
| AC-06 | Полная проверка CLAUDE.md проходит | вывод команд в handoff |
