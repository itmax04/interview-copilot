# COPILOT-02: Intent — точность Parakeet v3 на реальных вопросах

ID: COPILOT-02-intent · Статус: **draft** · Версия: 1 · Дата: 2026-10-22
Владелец результата: itmax04 · Связи: [spec.md](spec.md), [plan.md](plan.md), [executor-prompt.md](executor-prompt.md),
[handoff.md](handoff.md), [ADR-0001](../../decisions/ADR-0001-stack.md) (раздел «Уточнение 2026-10-08»),
предыдущая задача — [COPILOT-01](../COPILOT-01/report.md)
Источник: ревью интеграции Parakeet v3 в сессии Claude Code 2026-10-22 (ветка `feat/copilot-01`, коммит `3b690fc`,
FluidAudio 0.17.7). Код при ревью не менялся.

## Проблема
С v0.1.1 основной движок распознавания — Parakeet v3 (FluidAudio, Core ML). На коротких синтетических фразах он точен
(тестовый звонок v0.1.2: raw WER RU 7,29%, UK 9,28%, EN 3,25%), но ревью нашло места, где точность на настоящем
собеседовании не проверена или уже потеряна:

1. **Длинные вопросы не проверены.** Parakeet за один проход обрабатывает ≤ 15 с звука
   (`ASRConstants.maxModelSamples = 240_000`), а реплика может длиться до 25 с
   (`StreamingTranscriber.swift:47`). Фразы 15–25 с режутся на куски и склеиваются. По документации FluidAudio
   (`Documentation/ASR/LongTranscription.md`) места склейки — главный источник ошибок: пропуск слов,
   повторы, вспышки текста не на том алфавите у v3. Все 15 фраз тестового звонка короче 14 с (4,6–13,7 с).
2. **Нет средства от ошибок в терминах.** Больше всего ошибок v0.1.2 — технические термины и числа.
   У Whisper была подсказка из базы (`initial prompt`); Parakeet её не принимает: `ParakeetEngine.swift:34`
   получает `prompt`, а вызов `manager.transcribe` (строка 51) его не передаёт. Переключатель «Подсказывать
   распознаванию формулировки из базы» для Parakeet неактивен, замены ему нет.
3. **Фильтр шума для Parakeet не работает.** `noSpeechProbability` равен только 0 или 1 (`ParakeetEngine.swift:57`),
   поэтому проверка `< 0.8` в `StreamingTranscriber.swift:373` ничего не отсеивает. Короткий мусор на шуме
   («Угу.», «Да.») доходит до панели.
4. **Нет запасного движка при сбое загрузки.** `ListeningController.swift:276` проверяет только существование папки
   модели. Если установка Parakeet неполная, загрузка падает и распознавания нет, хотя Whisper установлен.
5. **Выбор языка в меню не влияет на Parakeet** — язык используется только как метка (`ParakeetEngine.swift:55`).
   В report.md COPILOT-01 выбор языка рекомендован как средство от путаницы uk ↔ ru; для Parakeet это не так.
6. **Мелкие расхождения:** логика закрепления языка разговора (`stickyLanguage`, пороги 0,7/0,75 подобраны под Whisper)
   выполняется для Parakeet впустую; усиление тихого звука до ×40 (`WhisperEngine.normalized`) взято у Whisper без
   замера для Parakeet; нет тестов самого адаптера `ParakeetEngine`; память на звонке с Parakeet + bge-m3 не замерена.

## Желаемый результат
Parakeet v3 остаётся основным локальным движком, и на вопросах собеседования любой длины:
1. длинные вопросы (15–25 с) распознаются не хуже коротких — это измерено, а при ошибках на стыках есть защита;
2. термины из базы вопросов владельца пишутся правильно чаще, чем в v0.1.2, и обычные слова не подменяются;
3. шум без речи не создаёт реплик в панели;
4. при сбое Parakeet приложение само переходит на Whisper и сообщает об этом;
5. интерфейс честно показывает, что выбор UK/RU для Parakeet — только метка, а выбор EN исключает кириллицу в тексте;
6. точность коротких фраз и задержка не хуже v0.1.2, память ≤ 1,5 ГБ.

Наблюдаемые метрики и проверки — AC-01…AC-12 в [spec.md](spec.md).

## Пользователи и системы
- Пользователь: один (владелец). MacBook Air M1, 8 ГБ, macOS 15.7.2.
- Системы: приложение InterviewCopilot (ветка `feat/copilot-01`, v0.1.2 build 3), FluidAudio 0.17.7, whisper.cpp `b5454`,
  модели Parakeet v3 (`FluidInference/parakeet-tdt-0.6b-v3-coreml`, ревизия из `parakeet-models.json`), Whisper (ggml).
- Площадки: тестовый звонок через Chrome (локальная страница приложения), Google Meet в Chrome.
  Zoom и Telegram в эту задачу не входят.

## Границы
Входит:
- синтетический набор длинных фраз (18–25 с) uk/ru/en и его прогон через движок и через тестовый звонок;
- защита от ошибок на стыках, если замер их покажет (настройка FluidAudio или своя нарезка ≤ 15 с по паузам);
- словарь терминов и исправление итогового текста по нему (для обоих движков);
- исследование усиления словаря через CTC (FluidAudio Custom Vocabulary) — только при разрешении владельца (Q3),
  по умолчанию выключено;
- фильтр коротких итогов с низкой уверенностью;
- переход на Whisper при сбое загрузки Parakeet и проверка полноты установки по манифесту;
- фильтр алфавита при явном выборе English; подписи в интерфейсе про язык для Parakeet;
- отключение sticky-логики для Parakeet, замер усиления тихого звука, smoke-тесты адаптера, замер памяти;
- воспроизводимый скрипт генерации фикстур тестового звонка (сейчас его в репозитории нет).

Не входит (кандидаты в следующие задачи):
- захват звука Zoom и Telegram, Core Audio process taps, браузеры кроме Chrome;
- новые движки распознавания (WhisperKit, Apple SpeechAnalyzer, Nemotron streaming), обновление FluidAudio;
- дообучение моделей;
- облачное распознавание;
- изменения поиска по базе, генерации ответов и интерфейса, кроме подписей про язык и статуса движка.

## Ограничения
- Всё распознавание локальное; аудио на диск не пишется (COPILOT-01 R-04, ADR-0001 «Уточнение 2026-10-08»).
  `ModelHub.offlineMode = true` во время работы.
- Память ≤ 1,5 ГБ (COPILOT-01 R-25/AC-05), включая словарь и, если будет принят, CTC-кодировщик.
- Задержка: медиана «конец фразы → итог» ≤ 1 с (COPILOT-01 AC-01); владелец ставит точность выше задержки,
  поэтому для длинных фраз допускается ≤ 1,5 с.
- Новые зависимости и модели — только с записью в ADR-0001 и разрешением владельца (CLAUDE.md).
  Модель Parakeet CTC 110M для усиления словаря — новая модель, нужна отдельная отметка (Q3).
- Данные в Git только синтетические (`evals/`, `profile.example/`). Записи голоса владельца и FLEURS — вне Git.
- Текст реплик в логи не пишется (COPILOT-01 R-24): словарь логирует только счётчики замен.
- Git: без force-push, `reset --hard`, удаления веток и merge в `main` (CLAUDE.md).

## Решения владельца
Ещё не приняты. Предложения исполнителя — в столбце «Предлагается»; ответ владельца заносится при H-0.

| № | Вопрос | Предлагается |
|---|---|---|
| Q1 | Откуда брать словарь терминов | Автоматически из `questions.yaml` (слова латиницей, аббревиатуры, слова с заглавной внутри фразы) + необязательный `profile/vocabulary.yaml` с вариантами написания |
| Q2 | Принять пороги AC-02, AC-04, AC-05 из spec.md | Да; уточняются по baseline на P-00/P-01 с записью в handoff |
| Q3 | Разрешить исследовать CTC-усиление словаря (скачать Parakeet CTC 110M ~100 МБ из Hugging Face FluidInference с SHA256) | Да, как ограниченное по времени исследование; включение по умолчанию — только после замера и отдельного решения |
| Q4 | Ветка | Новая `feat/copilot-02` от `feat/copilot-01` (она не слита в `main`); CLAUDE.md обновить на P-00 |
| Q5 | Исполнитель | Claude Code, `claude-opus-5-5`, effort high, как в COPILOT-01 |
| Q6 | Живая проверка на своём голосе (H-2) | Да: 3 длинных вопроса и 5 вопросов с терминами через Meet с телефона или свои записи вне Git |

## Допущения (не блокируют)
- A-1. Термины, которые важны владельцу, есть в `questions.yaml` или будут добавлены в `vocabulary.yaml`;
  общий словарь IT-терминов не составляется.
- A-2. Исправление по словарю применяется к итоговому тексту; промежуточный текст не исправляется (он и так меняется).
- A-3. Собеседник не говорит дольше 25 с без пауз ≥ 350 мс; предел реплики (`maxUtterance`) не меняется.
- A-4. Синтетические голоса macOS (`say`: Lesya, Milena, Samantha) достаточны для поиска ошибок на стыках;
  точность на живой речи подтверждает H-2.
- A-5. Если VAD режет синтетические длинные фразы на паузах между предложениями, фразы 15–25 с в реальном потоке
  редки; это записывается как результат, а не как провал AC-01.

## Открытые вопросы
Блокеров нет, кроме ответов Q1–Q6 при H-0. Проверяются по ходу:
- есть ли ошибки на стыках у Parakeet v3 на фразах 15–25 с (P-01);
- работает ли CTC 110M на кириллице или только на английских терминах в кириллической фразе (P-04, если Q3 = да);
- нужна ли нормализация громкости для Parakeet (P-08).
