# COPILOT-04: Спецификация — мгновенные ответы

ID: COPILOT-04-spec · Статус: **accepted** (2026-10-23) · Версия: 1 · Дата: 2026-10-23 · Владелец: itmax04
Связи: [intent.md](intent.md) · [handoff.md](handoff.md) · требования COPILOT-01 — с префиксом «01/», COPILOT-03 — «03/»

## Требования
- **R-01. Опережающий запрос.** Как только пришёл итог законченной реплики (≥ 3 слов, не оборвана, собеседник
  и владелец молчат, итог следующей фразы не ожидается), модель получает вопрос, не дожидаясь паузы T
  (`TurnDetector.draft`, `AnswerController.prefetch`). Ответ копится и показывается, когда ход с тем же текстом
  наступает (01/R-05); другой текст или пауза отменяют запрос. Карточка базы опережающего запроса не требует.
  Расход и ошибки ключей учитываются и у отменённых запросов (01/R-20). Настройка Audio
  «Начинать ответ заранее, не дожидаясь паузы», по умолчанию включено.
- **R-02. Пауза после вопроса.** Если реплика кончается «?», ход — через `questionPauseMs` (по умолчанию 350 мс,
  200–1500, не больше T). Начало с вопросительного слова — флаг `questionStarters`, выключен (на eval выигрыша нет).
- **R-03. Суть первой строкой.** Ответ начинается одной короткой фразой жирным, затем 2–5 пунктов, ≤ 80 слов.
- **R-04. Замер.** Журнал: `draft_start`, `draft_used` (старт от конца речи, запас до хода), `draft_cancelled`,
  `first_token … speculative=0|1`. `scripts/metrics.py`: метрика «конец речи → первые слова» и сводка
  опережающих запросов. `copilot-eval turn`: строка `draft:` (старт запроса, лишние запросы).
- **R-05. Импровизация.** Модель не пишет «не знаю», не отказывается и не ставит заглушек «[уточнить]»:
  при нехватке данных импровизирует правдоподобный ответ из контекста (вакансия, профиль, разговор, практика отрасли);
  личные факты профиля не противоречит, недостающие — общими словами, без выдуманных компаний и точных цифр.
  Вопрос с ошибками распознавания — отвечать на наиболее вероятный по контексту. Заменяет правило «[уточнить]»
  в 01/R-11 и 03/R-40.
- **R-06. Свой API (2026-10-23, запрос владельца «возможность добавлять свой api ключ»).** Провайдер `custom` —
  любой OpenAI-совместимый Chat Completions (OpenRouter, OpenAI, Together, Mistral, Ollama/LM Studio на этом Mac).
  Settings → Keys, блок «Свой API» сразу после Groq: адрес API, модель, ключ (Связка ключей), «Проверить» (`GET …/models`),
  «Поставить первым в цепочке». Адрес — только HTTPS; HTTP — только localhost/127.0.0.1 (01/R-23).
  Без адреса или модели провайдер в цепочку не входит и в строке «Models» не показывается. Параметры запроса — общие:
  `max_tokens` (для api.openai.com — `max_completion_tokens` и без `temperature`); изображения не отправляются.
  Бюджет его не выключает: цен приложение не знает, расход виден у провайдера.
