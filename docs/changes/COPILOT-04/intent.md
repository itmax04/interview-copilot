# COPILOT-04: Intent — мгновенные ответы без базы

ID: COPILOT-04-intent · Статус: **accepted** (2026-10-23, «да, делай пункты 1–4») · Версия: 1 · Дата: 2026-10-23 · Владелец: itmax04
Связи: [spec.md](spec.md), [handoff.md](handoff.md), [COPILOT-03 spec](../COPILOT-03/spec.md) (R-36…R-40), [ADR-0001](../../decisions/ADR-0001-stack.md)

## Проблема
Главная идея владельца: приложение мгновенно распознаёт вопрос и отвечает без подготовленной базы.
Без базы уже можно (COPILOT-03 R-40, «Без профиля»), но от конца вопроса до первых слов подсказки проходит ≈ 1,5–2 с:
0,7 с ждём паузу T, и только потом модель получает вопрос.

## Желаемый результат
Первые слова подсказки — не позже ~1 с после конца вопроса (медиана); модель не оставляет владельца без ответа.

## Решения владельца (2026-10-23)
| № | Вопрос | Решение |
|---|---|---|
| Q1 | Что делать | Пункты 1–4: опережающий запрос, короткая пауза после вопроса, суть первой строкой, замер |
| Q2 | Если модель не знает | Импровизировать и давать подсказки из контекста (сообщение владельца во время работы) |

## Границы
Входит: опережающий запрос, пауза для «?», порядок ответа, правило импровизации, метрики и офлайн-замер.
Не входит: снижение паузы VAD (350 мс), запрос по промежуточному тексту во время речи, новые провайдеры.

## Ограничения
- Лишние запросы к модели: опережающий запрос отменяется, если собеседник продолжил. Groq Free — 1000 запросов в день.
- Живой замер — с ключами владельца (Settings → Keys); исполнитель ключи не вводит.

## Допущения
- A-1. Parakeet ставит «?» по интонации; вопросы без «?» ждут обычную паузу T.
