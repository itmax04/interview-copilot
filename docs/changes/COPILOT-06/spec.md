# COPILOT-06: Спецификация — память интервью

ID: COPILOT-06-spec · Статус: **accepted** (2026-10-23) · Версия: 1 · Дата: 2026-10-23 · Владелец: itmax04
Связи: [intent.md](intent.md) · [handoff.md](handoff.md)

## Требования
- **R-01. Обмены.** Каждый ход интервьюера (01/R-05) — новый обмен; фразы владельца с микрофона на созвоне (05/R-07), прошедшие
  фильтры, — его ответ; показанная подсказка — `hint` (для разбора). `InterviewMemory`, `SessionExchange`.
- **R-02. Короткая память.** В запрос — 4 последних обмена целиком (вопрос ≤ 300, ответ ≤ 500 символов), блок `<interview_history>`
  с «N min ago». Текущий вопрос в историю не входит.
- **R-03. Долгая память.** Старые обмены индексируются bge-m3 (та же модель, что база, локально); на вопрос — до 3 похожих
  (порог 0,55) в блок `<earlier_in_interview>`. Отсылка к прошлому («вернёмся», «вы говорили», «раніше», «earlier you mentioned»…)
  — порог 0,35 и пометка для модели (`ReferenceDetector`).
- **R-04. Без выдумок.** Правило промпта: опираться на историю, не противоречить и не повторять; не придумывать прошлые ответы —
  если отсылка не найдена, отвечать по существу без «как я уже говорил». Ответ без записи — «(answer not recorded)».
- **R-05. Сессии.** Новая сессия — запуск, смена приложения звонка, тишина между ходами > 30 мин, меню «Новое интервью»:
  прошлая сессия сохраняется в историю (`SessionRecord.exchanges`), память очищается. Старые файлы истории читаются.
- **R-07. Подсказка вместо незаписанного ответа** (2026-10-23, по итогам живого теста). Если ответ владельца не записан,
  в историю идёт показанная подсказка (≤ 300 символов, без разметки) с пометкой «suggestion shown on screen, may not have been
  said»: факты (цифры, технологии, имена) держатся согласованными, но модель не утверждает, что кандидат это сказал.
- **R-08. «Сейчас отвечаю я» в самопроверке** — ⌃⌥A (переназначается в Hotkeys). В режиме «Микрофон Mac» речь до повторного
  нажатия — ответ владельца в память (не вопрос, без хода и подсказки); в панели — «Ваш ответ записывается». Выключается при
  смене источника; на созвоне не нужен (ответы слышны отдельным каналом).
- **R-06. Данные.** История — локально, срок хранения R-18 (30 дней); в запрос — фильтр ПД (01/R-12); в логи текст не пишется.

## Критерии приёмки
| AC | Критерий | Проверка |
|---|---|---|
| AC-01 | Возвраты к ранним темам (явные и неявные) находят нужный обмен — все случаи набора | eval `memory` |
| AC-02 | Новые темы не тянут старые обмены — не больше 1 случая | eval `memory` |
| AC-03 | Промпт: блоки истории как данные, правило «не выдумывать», фильтр ПД | `swift test` |
| AC-04 | Сессии изолированы, старые файлы истории читаются | `swift test` |
| AC-05 | На живом интервью возврат к теме через 20+ мин даёт подсказку по сказанному | владелец |
