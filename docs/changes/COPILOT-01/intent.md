# COPILOT-01: Intent — помощник на собеседованиях для macOS (v1)

ID: COPILOT-01-intent · Статус: **proposed** (ожидает принятия владельцем) · Версия: 1 · Дата: 2026-10-06
Владелец результата: itmax04 · Связи: [spec.md](spec.md), [plan.md](plan.md), [ADR-0001](../../decisions/ADR-0001-stack.md)
Источник решений: ответы владельца на вопросы Q1–Q12 в сессии Claude Code от 2026-10-06 (таблица ниже).

## Проблема
На онлайн-собеседованиях (Google Meet, Zoom, Telegram) владельцу трудно быстро вспомнить заранее подготовленный
ответ и сформулировать ответ на неожиданный вопрос. Готовые сервисы (например, Parakeet AI) платные
и хранят разговор у третьей стороны.

## Желаемый результат
Личное приложение для macOS, которое во время созвона:
1. слушает только собеседника и показывает расшифровку (uk/ru/en) с задержкой ≤ 1 с;
2. находит вопрос в базе ответов владельца и показывает готовый ответ за ≤ 0,5 с;
3. если вопроса нет в базе, по выбранному режиму генерирует подсказку (первые слова ≤ 2,5 с)
   через Gemini Flash (бесплатно) с переходом на DeepSeek или Claude;
4. по горячей клавише отправляет скриншот задачи в сильную модель и показывает решение.

Наблюдаемые метрики и проверки — AC-01…AC-14 в spec.md.

## Пользователи и системы
- Пользователь: один (владелец). MacBook Air M1, 8 ГБ, macOS 15.7.2.
- Системы: macOS (ScreenCaptureKit, AVFoundation, Keychain, TCC), whisper.cpp, локальная модель эмбеддингов,
  Gemini API, DeepSeek API, Anthropic API, GitHub (приватный репозиторий `itmax04/interview-copilot`).
- Площадки созвонов: Google Meet в Chrome (основная для тестов: Zoom не установлен), Zoom, Telegram.

## Границы
Входит в v1:
- приложение в строке меню и плавающая панель (дизайн по `docs/design/menu-v2.webp`);
- захват звука выбранного приложения, локальная расшифровка uk/ru/en, определение конца вопроса;
- база вопросов (`questions.yaml`), поиск по смыслу, режимы «Только база» / «База + подсказка» / «Генерация»;
- генерация: Gemini → DeepSeek → Claude, потоковый вывод, ручной вызов сильной модели;
- скриншот → сильная модель;
- настройки, ключи в Связке ключей, история сессий, учёт расхода, горячие клавиши ⌃⌥;
- evals для поиска по базе и определения конца вопроса.

Не входит в v1 (кандидаты в следующие intent):
- скрытие панели от демонстрации экрана (Q3 — нет);
- Jev и автоматическая классификация «сложных» вопросов;
- режим тренировки (в меню пункт неактивный, «скоро»);
- несколько профилей (в v1 один профиль);
- Windows, распространение, нотаризация, автообновление, платные аккаунты;
- озвучка (TTS) и запись аудио.

## Ограничения
- Память: всё приложение вместе с моделями ≤ 1,5 ГБ (8 ГБ на Mac делят ещё браузер и созвон).
- Бюджет: тестирование на бесплатном Gemini ($0). Платные провайдеры подключаются ключами позже;
  месячный лимит расходов на них по умолчанию $5 (настраивается).
- Данные: владелец разрешил отправлять резюме и расшифровки в Gemini и DeepSeek (Q6).
  Почта, телефоны и ссылки из профиля по умолчанию вырезаются перед отправкой.
- Ключи никогда не попадают в репозиторий, логи и чат.
- Инструменты: Swift 6 CLT есть; Xcode ставится, если без него не обойтись (Q10), — установку делает владелец.
- Git: приватный репозиторий, работа в ветке `feat/copilot-01`, без force-push (Q11).
- Исполнитель: Claude Code, `claude-opus-5-5`, effort high (Q8). Вопросы владельцу — только в точках H-0…H-5 (Q9).
- Риск использования: применение на реальных собеседованиях может нарушать правила работодателя —
  решение и ответственность владельца; на техническое решение не влияет.

## Допущения (не блокируют, можно исправить при приёмке)
- A-1. Ответ на Q2 читается как «предложенный состав v1 принят, основная модель — Gemini».
- A-2. Ответы генерируются на языке вопроса; карточки базы показываются как написаны владельцем.
- A-3. Горячие клавиши — ⌃⌥ вместо ⌘ с картинки (конфликты с Chrome, Meet, VS Code); можно переназначить.
- A-4. Строка «Gemini quota 92%» на картинке заменяется на счётчик запросов: Gemini API не отдаёт остаток квоты.

## Открытые вопросы
Блокеров нет. Неблокирующие вопросы проверяются на шагах плана:
- нужен ли Xcode для тестов (P-00 → H-0);
- уложится ли whisper large-v3-turbo в память и задержку на M1 8 ГБ (P-04, при неудаче — модель small);
- какая модель эмбеддингов даст ≥ 85% на перефразировках uk/ru/en (P-06).
