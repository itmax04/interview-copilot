# COPILOT-01: План тестирования (для следующего исполнителя-модели и владельца)

Дата: 2026-10-07 · Ветка: `feat/copilot-01` · Требования — [spec.md](spec.md), состояние — [report.md](report.md), журнал — [handoff.md](handoff.md).
Документ самодостаточен: новая сессия может начать с него, не читая переписку.

## 1. Контекст за минуту
- Нативное приложение macOS (Swift 6, SwiftPM, без .xcodeproj): строка меню + плавающая панель. Слушает собеседника
  в Meet/Zoom/Telegram (ScreenCaptureKit), расшифровывает локально (whisper.cpp, модель **medium q5_0**), ищет ответ
  в базе (эмбеддинги **bge-m3** через llama.cpp, порог 0,74), иначе генерирует подсказку (Gemini → запасная Gemini Flash-Lite →
  DeepSeek → Claude).
- Цели: `CopilotCore` (логика, тестируется), `CopilotEmbeddings` (llama.cpp), `InterviewCopilot` (AppKit/SwiftUI), `copilot-eval` (CLI).
- Данные: `~/Library/Application Support/InterviewCopilot/` (profile/, models/, sessions/, cache/, usage.json). Ключи — только Keychain
  (service `com.itmax04.interviewcopilot`). Настройки — UserDefaults `com.itmax04.interviewcopilot`, ключ `settings.v1` (JSON).
- Правила проекта — `CLAUDE.md` (запреты: force-push, reset --hard, merge в main, TCC/Keychain trust, ключи в чат/код).

## 2. Среда и подготовка
| Что | Как |
|---|---|
| Mac | Apple Silicon, macOS 15+ (проверено: M1 8 ГБ, 15.7.2), **Xcode 26.3** (`xcode-select -p` → Xcode.app) |
| Сертификат | «InterviewCopilot» (или «InterviewCopilot Dev») в связке «вход»; `security find-identity -p codesigning` |
| Модели | `scripts/fetch-models.sh` (≈ 1,7 ГБ: whisper medium, small, turbo, bge-m3, embeddinggemma — проверка SHA256) |
| Разрешения | Запись экрана и системного звука + Микрофон для InterviewCopilot (выдаёт **только владелец**) |
| Ключ Gemini | Вводит владелец в Settings → Keys. Значение ключа никогда не читать/не выводить |

Особенности окружения, о которые уже спотыкались:
- Репозиторий на «Рабочем столе» в **iCloud Drive**: `build-app.sh` подписывает бандл во временной папке и копирует в `dist/`
  (иначе codesign: «detritus not allowed»). Не убирать это.
- В zsh `log` — встроенная команда: использовать `/usr/bin/log`.
- Метрики пишутся уровнем **notice** (info живёт только в памяти).
- **Связка ключей:** после каждой пересборки приложение один раз спрашивает доступ к ключу (самоподписанный сертификат) —
  владелец жмёт «Разрешать всегда». Пока окно висит, генерация ждёт. Не пересобирать без нужды во время теста владельца.
- **Квота Gemini Free** маленькая: каждый `--smoke-llm` тратит запросы. Не гонять живые запросы циклом.
- У процесса агента **нет** разрешения «Запись экрана»: `screencapture` даёт только обои, синтетические нажатия не работают.
  Всё визуальное и горячие клавиши проверяет владелец.
- Перед `scripts/build-app.sh` закрыть приложение (`pkill -x InterviewCopilot`): подмена бандла у работающего процесса
  ломает подпись на лету.

## 5. Что осталось проверить (приоритет сверху вниз)
1. **AC-10, точность uk/ru/en на созвоне.** Сценарий — `evals/live-script.md`. Сделать две серии: (а) Language = Auto,
   (б) Language выбран явно. Лучше собеседник с ноутбука/гарнитуры, телефон не в одной комнате с Mac. Владелец оценивает
   «понятно ≥ 4 из 5» на каждый язык. Английские вопросы 11–15 вживую ещё не читались.
2. **AC-09, горячие клавиши при активном Chrome:** ⌃⌥H (панель исчезает/появляется, курсор остаётся в адресной строке),
   ⌃⌥↩ (ответ сразу), ⌃⌥S (решение по скриншоту), ⌃⌥P (пауза: статус Paused, ничего не уходит в модель), ⌃⌥C
   (без ключа Anthropic кнопка «↑ Claude» неактивна с подсказкой «Нет ключа Anthropic»).
3. **AC-13, без разрешения:** владелец снимает переключатель InterviewCopilot в «Конфиденциальность → Запись экрана
   и системного звука», запускает приложение: красная точка в меню, панель «Нет разрешения… Открыть Системные настройки»,
   окно разрешений/мастер, приложение не падает. Потом включить обратно (перезапуск).
4. **AC-07 вручную:** в Settings → Keys временно ввести заведомо неверный ключ Gemini → «Проверить» показывает
   «Ключ недействителен»; при ходе вне базы — «Модели недоступны: …» и топ-3 (без запасных ключей). Вернуть правильный ключ.
5. **DeepSeek и Anthropic вживую** — только когда владелец добавит ключи: `--smoke-llm`, затем ⌃⌥C; проверить метку
   фактической модели и `usage.json` (стоимость, лимит месяца).
6. **AC-05 под нагрузкой:** 10 минут созвона с речью + `scripts/footprint-monitor.sh 10`.
7. **S-09, мастер первого запуска на «чистом» профиле:** переименовать `~/Library/Application Support/InterviewCopilot/models`
   (только с согласия владельца — 1,7 ГБ скачивать заново) и проверить загрузку с прогрессом и SHA256; либо проверить на другой учётке.
8. **S-10:** правка `profile/questions.yaml` с ошибкой → в меню «Question bank: ошибка в строке N», прежняя база работает;
   исправить → число карточек обновилось (уже проверено по логам, нужен визуальный взгляд).
9. **Режим «Microphone (practice, no call)»:** Listening → Microphone; говорить в микрофон Mac вопросы из базы и вне базы;
   ожидается расшифровка и ответ; переключение обратно на Auto возвращает захват Chrome и определение речи владельца.
10. **R-19 окно истории:** «Session history…» — список, просмотр, удаление одной и всех.

## 6. Известные слабые места (куда смотреть при ошибках)
| Симптом | Где | Что известно |
|---|---|---|
| Неточный текст | `STT/WhisperEngine.swift`, `STT/StreamingTranscriber.swift` | Сжатый звук Meet. Опция Settings → Audio «Подсказывать формулировки из базы» (initial prompt) — смешанный эффект, выключена. Контекст прошлых реплик в подсказке ломал вывод — убран |
| Неверный язык uk ↔ ru | `resolveLanguage` в `StreamingTranscriber` | Детектор whisper на первых ~1,2 с ненадёжен; сравнение uk/ru по средней вероятности токенов; «язык разговора» после 2 уверенных реплик пропускает детектор (~1,5 с на medium, не прерывается) |
| Итог фразы > 1 с | то же | Итог ждёт непрерываемый детектор языка, если фраза кончилась во время него. Явный язык в меню убирает задержку |
| Подсказка не приходит | `LLM/ProviderChain.swift` | `ProviderHealth`: модель с таймаутом/429/5xx 5 минут в конце очереди. Квота Gemini Free |
| Автоответ не срабатывает | `Turns/TurnDetector.swift` | Владелец «говорит» (микрофон, порог −36 dBFS); эхо динамиков фильтруется (150 мс после и 500 мс до речи собеседника). Лог: `mic_db`, `owner_speaking` |
| Тихий собеседник | `StreamingTranscriber.Config.vad` | VAD −62 dBFS + шум+10 дБ; усиление до пика 0,5 (≤ ×40) |
| Окно Связки ключей | — | Самоподписанный сертификат; «Разрешать всегда» после каждой пересборки |

## 7. Приёмка владельцем (H-5), ≈ 15 минут
1. Запустить `dist/InterviewCopilot.app` (если спросит Связку ключей — «Разрешать всегда»; мастер — всё зелёное → «Готово»).
2. Меню попугая похоже на `docs/design/menu-v2.webp` (⌃⌥ вместо ⌘, «Practice mode … soon», строка «Today: $… · Gemini: N req»). — AC-11
3. Meet в Chrome, собеседник говорит 3 вопроса из базы и 2 вне базы: карточка «Bank · … · NN%» или «Gemini · generated». — AC-08
4. При активном Chrome: ⌃⌥H дважды, ⌃⌥↩, ⌃⌥S, ⌃⌥P дважды. — AC-09, S-06, S-08
5. «Session history…»: сессия есть, удаляется. — AC-12
6. Решение по AC-10 (точность) и NOT RUN (DeepSeek/Anthropic, английский вживую, AC-13 визуально).
