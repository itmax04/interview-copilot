## Решения исполнителя
- Один распознаватель вместо двух: источники переключаются маршрутом. Два `StreamingTranscriber` на одном
  `ParakeetEngine` отменяли бы чужие прогоны (`cancel()` общий для движка).
- Голос через WAV во вкладке Chrome, а не `speechSynthesis` браузера: системный синтез macOS играет звук из своего
  процесса, и фильтр захвата Chrome его бы не услышал.
- Вопрос идёт в обычный конвейер хода и подсказок — это и есть проверка «как на созвоне». Ответ владельца — нет.
- Таймаут первого токена для вопроса 20 с: при перегрузке Gemini 4 с не хватало (503 и таймаут запасной модели).

## Известные ограничения
- Gemini Free перегружен (503, медленный первый токен): вопрос может готовиться 10–30 с.
- Фильтр ПД (R-12) не распознаёт телефоны с другой группировкой цифр, например немецкий номер «+49 151 …» с восемью цифрами подряд (существующее ограничение `PIIFilter`).
- Голос интервьюера синтетический: точность вопросов не равна точности на живом собеседнике; живой голос измеряется правкой ответов.
