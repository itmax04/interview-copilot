# COPILOT-03: Спецификация — ИИ-собеседование

ID: COPILOT-03-spec · Статус: **accepted** (2026-10-22) · Версия: 1 · Дата: 2026-10-22 · Владелец: itmax04
Связи: [intent.md](intent.md) · [handoff.md](handoff.md) · требования R-01…R-23 — [COPILOT-01 spec](../COPILOT-01/spec.md)

## Сценарии
- **S-30. Собеседование.** Дано: Chrome установлен, разрешения «Запись экрана и системного аудио» и «Микрофон» выданы,
  модель распознавания загружена. Когда: владелец выбирает «ИИ-собеседование…», язык, число вопросов и жмёт «Начать».
  Тогда: модель генерирует вопрос, голос macOS читает его во вкладке Chrome, приложение распознаёт вопрос
  (страница показывает эталон и услышанное с подсветкой ошибок), в панели появляется карточка или подсказка;
  затем владелец отвечает в микрофон, ответ распознаётся, модель задаёт следующий вопрос.
- **S-31. Конец ответа.** После N с тишины (настройка страницы, 3/5/8 с или «только по кнопке») или по «Я ответил»;
  начатые фрагменты дораспознаются (не дольше 15 с).
- **S-32. Правка ответа.** Владелец исправляет распознанный ответ — страница показывает WER ответа.
- **S-33. Ошибка модели.** Все модели цепочки не ответили — сообщение и кнопка «Повторить запрос».
- **S-34. Завершение.** «Завершить» или закрытие вкладки возвращают прежний источник звука и режим микрофона.

## Требования
- **R-30. Голос.** AVSpeechSynthesizer, лучший установленный не-новелти голос языка (uk-UA, ru-RU, en-US);
  WAV PCM16 моно в памяти, 0,8 с тишины до и 0,7 с после речи; отдаётся только по токену сессии.
- **R-31. Модель.** Цепочка из настроек (R-09), таймаут первого токена не меньше 20 с; промпт — `InterviewerPrompt`:
  один вопрос ≤ 35 слов, только выбранный язык, числа словами, без разметки; вакансия, резюме и ответы — данные,
  а не инструкции; фильтр ПД (R-12) для резюме и ответов. Расход учитывается как у подсказок (R-20).
- **R-32. Источники.** Во время собеседования в распознавание идёт ровно один источник: звук Chrome при вопросе,
  микрофон при ответе (`AudioRoute`). Переключение сбрасывает незаконченные фрагменты. Распознавание ответа
  владельца не попадает в расшифровку собеседника, подсказки и историю сессий.
  **Исключение из R-02 COPILOT-01:** в этом режиме микрофон владельца расшифровывается — по решению Q1.
- **R-33. Метрики.** Для вопроса — WER «текст модели → распознанное» и задержка «конец речи → текст» (как `TestCallTrial`);
  для ответа — длительность речи и, после правки, WER. Отчёт JSON — только по кнопке, в браузере.
- **R-34. Безопасность страницы.** Как у тестового звонка: только 127.0.0.1, случайный токен, проверка Host/Origin,
  закрытие через 90 с без запросов.

## Критерии приёмки
| AC | Критерий | Проверка |
|---|---|---|
| AC-30 | Вопрос модели звучит во вкладке Chrome и распознаётся через захват; WER и задержка видны на странице | Владелец, живой прогон |
| AC-31 | Ответ владельца распознаётся с микрофона, не попадает в панель как реплика собеседника | Владелец + лог `interviewer_answer` |
| AC-32 | Следующий вопрос учитывает ответ (уточнение) | Владелец |
| AC-33 | После «Завершить» источник и микрофон как до собеседования | Владелец |
| AC-34 | Юнит-тесты промпта, WAV, `AnswerCapture`, правки и синтеза | `swift test` |
