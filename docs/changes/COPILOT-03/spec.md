# COPILOT-03: Спецификация — ИИ-собеседование

ID: COPILOT-03-spec · Статус: **accepted** (2026-10-22) · Версия: 1 · Дата: 2026-10-22 · Владелец: itmax04
Связи: [intent.md](intent.md) · [handoff.md](handoff.md) · требования R-01…R-23 — [COPILOT-01 spec](../COPILOT-01/spec.md)

## Сценарии
- **S-30. Собеседование.** Дано: Chrome установлен, разрешения «Запись экрана и системного аудио» и «Микрофон» выданы,
  модель распознавания загружена. Когда: владелец выбирает «ИИ-собеседование…», язык, число вопросов и жмёт «Начать».
  Тогда: модель генерирует вопрос, голос macOS читает его во вкладке Chrome, приложение распознаёт вопрос
  (страница показывает эталон и услышанное с подсветкой ошибок), в панели появляется карточка или подсказка;
  затем владелец отвечает в микрофон, ответ распознаётся, модель задаёт следующий вопрос.
- **S-31. Конец ответа.** После N с тишины (настройка страницы, 3/5/8 с или «только по кнопке») или по «Я ответил»;
  начатые фрагменты дораспознаются (не дольше 15 с).
- **S-32. Правка ответа.** Владелец исправляет распознанный ответ — страница показывает WER ответа.
- **S-33. Ошибка модели.** Все модели цепочки не ответили — сообщение и кнопка «Повторить запрос».
- **S-34. Завершение.** «Завершить» или закрытие вкладки возвращают прежний источник звука и режим микрофона.

## Требования
- **R-30. Голос.** AVSpeechSynthesizer, лучший установленный не-новелти голос языка (uk-UA, ru-RU, en-US);
  WAV PCM16 моно в памяти, 0,8 с тишины до и 0,7 с после речи; отдаётся только по токену сессии.
- **R-31. Модель.** Цепочка из настроек (R-09), таймаут первого токена не меньше 20 с; промпт — `InterviewerPrompt`:
  один вопрос ≤ 35 слов, только выбранный язык, числа словами, без разметки; вакансия, резюме и ответы — данные,
  а не инструкции; фильтр ПД (R-12) для резюме и ответов. Расход учитывается как у подсказок (R-20).
- **R-32. Источники.** Во время собеседования в распознавание идёт ровно один источник: звук Chrome при вопросе,
  микрофон при ответе (`AudioRoute`). Переключение сбрасывает незаконченные фрагменты. Распознавание ответа
  владельца не попадает в расшифровку собеседника, подсказки и историю сессий.
  **Исключение из R-02 COPILOT-01:** в этом режиме микрофон владельца расшифровывается — по решению Q1.
- **R-33. Метрики.** Для вопроса — WER «текст модели → распознанное» и задержка «конец речи → текст» (как `TestCallTrial`);
  для ответа — длительность речи и, после правки, WER. Отчёт JSON — только по кнопке, в браузере.
- **R-35. Украинский итог (2026-10-23, жалоба владельца: украинская речь распознаётся как русская).**
  Parakeet не закрепляет язык. При движке Parakeet и включённой настройке «Украинский итог — через Whisper turbo»
  (по умолчанию да, нужен файл turbo) итог фразы распознаёт Whisper large-v3-turbo с языком `uk` и полным контекстом,
  если язык выбран «Українська» или в тексте Parakeet есть і/ї/є/ґ. Предварительный текст, русский и английский — Parakeet.
  Whisper загружается при первой украинской фразе; при ошибке загрузки или пустом итоге остаётся текст Parakeet.
- **R-36. Быстрые модели и параллельный запуск (2026-10-23, запрос владельца: «автоматически менялись и отвечали сразу»).**
  Провайдеры Groq (`openai/gpt-oss-120b`, бесплатно 1000 запросов/день) и Cerebras (`gpt-oss-120b`, пробные кредиты),
  OpenAI-совместимый API; по умолчанию первыми в цепочке (миграция схемы 6 ставит их в начало сохранённой цепочки).
  Если попытка молчит `hedgeAfter` (1,5 с), тот же запрос сразу уходит следующей модели; побеждает первая с текстом,
  остальные отменяются; не больше двух попыток одновременно. Бюджет месяца Groq/Cerebras не выключает.
- **R-37. Двухэтапный итог.** Ход и подсказка — по быстрому итогу Parakeet (≈0,5 с). Уточнённый итог Whisper turbo
  (украинский — всегда при включённом R-35; русский/английский — настройка, по умолчанию да) приходит событием `revised`
  и заменяет строку в расшифровке и истории; тестовый звонок и ИИ-собеседование оценивают уточнённый текст.
  Модели передаётся язык ответа: выбранный в меню или украинский, если в вопросе есть і/ї/є/ґ.
- **R-38. Шум не блокирует ход.** Реплика без текста даёт событие `discarded`; ожидание потерянного итога — не дольше 8 с,
  «собеседник говорит» — не дольше 30 с. Если итоги идут, а ходов нет, раз в минуту в журнал пишется `turn_stall` с состоянием.
- **R-39. Захват восстанавливается.** Остановка потока macOS или значком в строке меню — перезапуск через 1 с,
  не больше 5 раз за 10 минут; затем ошибка в панели.
- **R-40. Ответы без профиля (2026-10-23, запрос владельца: «модель отвечала независимо от профиля и сама давала ответы
  без подсказок»).** Подменю Profile: название профиля (как было) или «Без профиля — модель отвечает сама»; выбор
  сохраняется (`useProfile`, по умолчанию профиль), заголовок пункта — «Profile: Без профиля».
  - Без профиля: резюме, вакансия, истории и база вопросов модели не передаются и не ищутся; на каждый ход генерируется
    ответ независимо от режима Mode; личный опыт модель приводит правдоподобным примером, без «[уточнить]».
    ИИ-собеседование без профиля задаёт общие вопросы для разработчика. Нет ключей — «Модели недоступны: нет ключей».
  - С профилем: технические, общие и концептуальные вопросы модель отвечает сама из своих знаний; «[уточнить]» —
    только для отсутствующих личных фактов (места работы, проекты, даты, цифры). Остальное поведение R-08/R-11 не меняется.
  - Уточнение 2026-10-23 (COPILOT-04 R-05): «[уточнить]» больше не ставится — недостающее модель импровизирует из контекста.
- **R-34. Безопасность страницы.** Как у тестового звонка: только 127.0.0.1, случайный токен, проверка Host/Origin,
  закрытие через 90 с без запросов.

## Критерии приёмки
| AC | Критерий | Проверка |
|---|---|---|
| AC-30 | Вопрос модели звучит во вкладке Chrome и распознаётся через захват; WER и задержка видны на странице | Владелец, живой прогон |
| AC-31 | Ответ владельца распознаётся с микрофона, не попадает в панель как реплика собеседника | Владелец + лог `interviewer_answer` |
| AC-32 | Следующий вопрос учитывает ответ (уточнение) | Владелец |
| AC-33 | После «Завершить» источник и микрофон как до собеседования | Владелец |
| AC-34 | Юнит-тесты промпта, WAV, `AnswerCapture`, правки и синтеза | `swift test` |
| AC-35 | Украинский итог без сползания в русский на голосе владельца | ИИ-собеседование на украинском с правкой ответов, A/B с выключенной настройкой |
| AC-36 | Без профиля ответ генерируется на каждый ход без резюме и базы; с профилем технический вопрос отвечается без «[уточнить]» | `swift test` (PromptBuilder, AnswerRouter, MenuLayout, Settings, Interviewer) + владелец на ИИ-собеседовании |
